# Student Task Manager

A beginner-friendly Java project designed to help students manage their academic tasks and deadlines.

## 🎯 Project Goal

The goal of this project is to practice Java programming and build practical software development skills.

## 🚀 Planned Features

* Add new tasks
* View all tasks
* Mark tasks as completed
* Delete tasks
* Manage assignment deadlines

## 🛠️ Technologies

* Java
* Object-Oriented Programming (OOP)

## 📌 Project Status

Currently in development. More features will be added as I learn and improve.
